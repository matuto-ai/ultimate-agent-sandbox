# Disposable native artifacts resources (source integration)

This explicitly selected artifacts-only profile extends the prepared native Git
profile. It is not command/diff qualification or production launcher enablement.
The no-Gate fixture/default remains unchanged. Real helper success, held exit,
postproof and cleanup evidence remain required; source checks do not claim kernel
Landlock/seccomp admission or provider/network isolation was executed.

`gate_manifest` is a public digest-bound reference to exact version1 fields:
`profile: artifacts-v1-source`, `image_id`, `image_reference`, `helpers` and
`host_materializer`. The image must equal the same selected Pi/Claude/Git image.
`helpers` pins `/opt/uas/bin/artifact-bootstrap` and `artifact-evaluator`; actual
bounded exact-container archive readback checks hashes, immutable ownership and
static ELF64 x86-64 program headers (no interpreter/dynamic section/W+X).
`host_materializer` separately pins `/usr/bin/git` and `/usr/bin/prlimit` on the
trusted Supervisor host. These are the existing bounded copied-object-store
materializer, not the Workstation controlled public Git launcher. No package,
image build or existing installation repair is performed by this selection.

The optional root profile prepares only fresh owned directories. Target scratch
and private retained target/launch journals are assigned XFS project301 on the
existing Room filesystem; no Project ownership/metadata changes. Exact root-owned
scratch identity evidence fences the quota observer before and after its read.
Target root is Supervisor165533-owned0711; target IDs remain private helper-group
parents as required by ArtifactTargets. Only scratch and the private Gate endpoint
directory are mounted, both readonly, at `/uas/gate-targets` and `/uas/gate`.
Journals are not mounted. No generic nested mount exception is granted.

Supervisor child receives narrowly selected supplemental group165530 only for
this profile. It creates/listens the socket itself with primary UID/GID165533,
helper-group165530 and0620; root chown of a root-created socket is not equivalent.
Stock MAC socket admission is a real qualification prerequisite, not an inferred
consequence of pathname ownership. There is no account setup or custom SELinux
rule/domain-transition fallback.

The existing root checkout handoff accepts only an Evaluation identifier for
quota observation, resolves the canonical reserved artifacts row, and snapshots
then rechecks it outside the actual OS read. The resource consumer independently
rechecks the canonical active operation before/after the call. Strict fixed
project report parsing uses actual used bytes plus every outstanding/quarantined
reservation, including the current32MiB reservation exactly once. Conservatively
counting existing reserved bytes already in actual usage is intentional. Retained
journals remain charged after released reservations. There is no second store,
caller-selected quota path/limit, or promise that concurrent Participant growth
cannot exhaust capacity after observation; hard quota and normal quarantine/error
handling remain authoritative. All observation commands honor the session deadline.

Fresh Gate launch admission inspects the same actual running provider-connected
native Workstation against the exact existing native container predicate, holds
its genuine Git-resource PID1/mapping identity and checks the exact combined
mounts. It does not reuse the VM network-none/256MiB predicate. Static helper
mandatory environment scrub, Landlock and seccomp refuse unsupported setup; only
actual successful protocol evidence can qualify helper confinement.

Diff would additionally require two exact target leases and64MiB plus a trusted
Broker base/head subject. Command would additionally require a separate hard8MiB
nosuid/nodev/noexec tmpfs, readonly noexec source, pinned command/runtime closure
and complete child-tree exit proof, reserving40MiB. Neither is enabled here.
